## 2026-10-30 旅行地理志

根据用户分享的 EdwardX 抖音图文提示词整理：
<https://v.douyin.com/qkw2PzKow84/>

应用中的“旅行地理志”保留真实摄影，将海岸线、城市街道、山脉等高线或河流作为
15%–25% 的半透明地理图层叠加在照片留白处，用一个朱红定位点和少量英文地名
建立编辑感。提示词明确禁止伪造精确 GPS、传统地图卡片、图钉、护照章和贴纸装饰。

这是提示词工作流，不下载 LoRA，也不切换第三方模型；生成仍使用用户选择的妙极模型。

## 2026-10-30 旅行 Skill 增量与去重

根据本轮分享的抖音内容新增三张、升级一张：

- 旅行冰箱贴：来源为“我佛糍粑粑”的固定旅行海报模板，
  <https://v.douyin.com/tmvCtJgPBdY/>。保留 2:3、上方约 45% 哑光背景与
  小型珐琅冰箱贴、下方 55% 原摄影的结构，并扩写材质、提取规则和负面约束。

  <https://v.douyin.com/jcXxqqlYtkM/>，因此合并为一张，不重复占卡位。
- 旅行贴纸卡：来源为“Carito”的 travel memory sticker card，
  <https://v.douyin.com/AuotFVMqjF4/>，对应开源仓库

  本应用没有复制原 `SKILL.md`，仅依据公开分享图和视觉规则独立重写提示词。
