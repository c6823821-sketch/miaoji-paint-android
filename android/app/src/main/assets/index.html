开源模型说明

开源 ≠ 免费

“开源”是指模型的代码和权重公开，通常可以下载、修改或自己部署。生成图片仍需要 GPU，租用云端算力会产生费用。本应用里的开源模型都在云端运行，手机只是控制台。

FLUX.1 Schnell 开源文生图

Black Forest Labs 的快速模型，擅长写实、摄影和复杂细节。Cloudflare 渠道先用账户免费额度，超额后计费。

Stable Diffusion XL / DreamShaper 开源文生图

SDXL 生态成熟，通用性强；DreamShaper 更偏写实和插画。它们并不天然免费，本应用使用 Cloudflare 的额度。

FLUX Kontext 开源图生图

按提示词修改上传的图片，例如换背景、改服装或转换画风。通过 Pollinations 使用 Pollen 余额。

Qwen Image 2.1 Turbo 开源文生图 / 参考图

阿里 Qwen 图像模型，中文语义和文字排版能力较好。通过 Pollinations 使用 Pollen 余额。

附加风格只会在你的提示词末尾追加摄影、电影感、动漫等要求，不会改变模型本身。想按自己的方式写，就选择“不加额外风格”。
