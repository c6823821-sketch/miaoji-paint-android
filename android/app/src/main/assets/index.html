风格与特效怎么用

选风格，不改模型

可以一次上传 1–6 张参考图。选一张风格卡片就能直接改图，提示词可以留空。纯文生图仍需写明主体。它不会启用额外收费模型，也不会下载 LoRA 文件。

热门风格 已整理

参考社区高收藏类型整理：油画厚涂、动漫插画、电影胶片、高级卡片。重点放在构图、材质、光线和色彩控制。

热门特效 独立人像板块

卡片显示妙极实际生成的成品。选择特效后，上传照片可先在大图里免费预览色调；点“生成特效照片”才会上传并扣费。

绘画与插画 提示词风格

水彩、水墨、动漫线稿、漫画赛璐璐、像素游戏和奇幻史诗。每个卡片都可直接点选。

设计卡片 海报 / 卡片

故事绘本、纸艺卡片、复古海报和高级编辑设计。适合封面、配图和社交媒体卡片。

旅行手账拼贴 3:4 · 需要照片

上半保留真实旅行照片，下半延展到米白纸面和黑色手绘线，只设计一个由照片景物转化出的互动。

3D 与手办 材质风格

3D 黏土和盲盒手办，强调圆润造型、柔软材质和棚拍布光。

每次只选一个主风格。需要混搭时，直接在提示词里补充，例如“油画厚涂 + 电影逆光”。选择“不加额外风格”就完全按你写的生成。
